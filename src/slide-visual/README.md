# スライド画像を統一スタイルで作成

スキル名：`slide-visual`　版：**1.1.0**  
初期版作成日・更新日：2026年9月18日

## できること

会話で議論したスライド内容から、PowerPointに差し込む画像を作ります。用途・構図・比率・抽象度・強調点など、結果を実質的に変える未確定事項を1問ずつ確認し、画像ごとに説明量を選びます。PowerPointファイル全体の作成・編集は対象外です。

## 明示して使う

**任意＝ユーザーが意図的にこのSkillの利用を指定する場合だけ適用する**設計です。未選択で「Slide 10 の画像」と書いたことだけを、利用許可とは扱いません。

ChatGPTでは `@` からスキルを選択できます。[1] 選択した状態で、次のように対象を伝えます。

```text
Slide 10
```

または、本スキルの利用を文章で明示します。

```text
slide-visualを使って、スライドの3枚目に入れる画像を作って。
右半分に配置します。文字はなし。
```

確認中の数字・自由入力への回答、生成画像への明確な修正には、スキル名を毎回付け直す必要はありません。新しい画像を同じ方法で作る場合は、次のように継続を明示します。

```text
同じSkillでSlide 11も作って。
```

中止や別の話題への移行後は、古い質問の回答待ち状態を引き継ぎません。対象スライドが参照できない場合は、その本文または利用可能な資料を提示します。

## 固定するもの・画像ごとに決めるもの

| 項目 | 設定 |
| --- | --- |
| 起動 | 明示利用だけ。題材一致による自動適用をしない |
| 統一する範囲 | Skill全体で1つの標準スタイル |
| 画風 | 落ち着いたフラットデザイン。ベタ塗り・装飾控えめ。影・3D・グラデーションなし |
| 配色 | ブルー・ネイビー・グレー |
| 背景 | 透過を標準とする |
| 質問が必要な初回 | スライドの理解を1〜2文で示し、同じ応答で1問確認 |
| 確認対象 | 用途・内容・構図・比率・抽象度・強調点など。毎回全項目を質問するわけではない |
| 確認形式 | 0／1／2／3／9を基本とし、1問ずつ回答後に再評価。回答済み・固定条件は聞き直さない |
| 説明量 | 新しい画像ごとに、1：ラベルのみ／2：文字なし／3：ラベル＋短い説明から確定 |
| 説明量の引き継ぎ | 同じ画像の修正・同条件での再試行は維持。別画像・別案へ黙って流用しない |
| 一時例外 | 「今回は」など範囲が明示済みなら、その範囲を再確認しない |
| 確認不要の場合 | 説明量を含め条件が確定済みなら、質問や承認を増やさず生成へ進む |

毎回の説明量選択は、毎回の再質問を意味しません。「文字なし」と今回の依頼に書けば選択済みです。文字量以外の質問は実質2案なら2案にし、全質問を3択へ水増ししません。`0` は直前の論点だけの委任、`9` は追加説明後の同じ論点の再質問です。

`guided-clarification` と同等の確認判断を本体へ組み込んでおり、別スキルのインストールは必須ではありません。一般の確認とは別に、未指定の説明量は画像ごとに必ず確定する特則があります。資料全体の説明量固定は既定機能に追加していません。

## 制作基準と限界

主色 `#3B82F6`、濃色 `#1E3A5F`、補助色 `#94A3B8`／`#E2E8F0`、外周の安全余白おおむね5〜10%は初期版の基準を維持しています。カラーコードと余白の具体値は、選択された画風を実装するために補った初期値であり、ユーザーが数値を個別指定したものではありません。

同じ図形・色値・文字・画風の完全一致は保証しません。透過の指示と、実ファイルの透明性の検査は別です。形式を指定できる場合は透過PNGを優先しますが、未確認の出力形式を断言しません。編集可能なSVGの図形を出力する仕様ではありません。

実行には、画像生成機能を利用できる環境が必要です。機能の利用可否は環境に従います。[3] 外部アプリ、APIキー、追加スキルを依存関係に含めていません。

## 起動設定と導入後の確認

`agents/openai.yaml` に次の設定を含めています。

```yaml
policy:
  allow_implicit_invocation: false
```

公式資料では、この設定によってCodexの暗黙起動を無効にできることが明記されています。[1] **ChatGPT Web/Desktopでも同じ設定が必ず同じように反映されると、このZIPだけからは保証しません。** 明示起動専用の説明文と本体の制御も併用し、利用先で実際の明示起動・非適用・継続を確認してください。

導入・更新の操作は、利用環境の最新の公式案内を参照してください。[2] 2026年9月18日の確認時点では、スキルの作成画面からコンピューターのファイルをアップロードする案内があります。画面名や利用可否は参考情報とし、本Skillの動作規則から分離します。既存版への反映方法は利用画面に従い、同名ファイルのアップロードだけで既存版が置換されたと決めつけないでください。

導入後は、明示選択で開始すること、未選択の通常依頼には本Skillを適用しないこと、数字への回答で継続することを確認します。「画像が出たか」だけでは非起動テストになりません。通常の画像生成と本Skillの適用を区別し、起動表示や実行記録を取得できない場合は、非起動を確認済みと断言しないでください。

ZIPの作成・検査・配布は、アカウントへのインストール、既存版への反映、設定の変更、実行試験の完了を意味しません。

## ファイル構成と保守

```text
slide-visual/
  SKILL.md
  agents/openai.yaml
  README.md
  CHANGELOG.md
  references/test-cases.md
```

動作ルールの正本は [SKILL.md](SKILL.md) です。変更点は [更新履歴](CHANGELOG.md)、受入テストは [確認ケース](references/test-cases.md) を参照してください。変更時は本文・説明文・起動ポリシー・README・テストケースの整合を確認します。スクリプト、認証情報、フォントファイル、外部画像は同梱していません。

## 検証状況

配布時の静的検査と、導入先の会話動作・画像生成の実地検証を区別します。今回の更新では、構造、YAML、内部参照、旧版から維持したスタイル・文字量定義、配布ZIPと編集ファイルの一致を検査しています。実地テストの期待結果を記載しただけで、会話動作や画像品質の合格とは扱いません。
