# 更新履歴

## 1.1.0 — 2026年9月18日

今回の会話で確定した条件と再検証結果を反映しました。

### 変更

- 起動を明示利用専用に変更。「Slide X の画像」など題材一致だけでの自動適用条件を削除。
- `agents/openai.yaml` に `policy.allow_implicit_invocation: false` を追加。記述と導入先での実際の反映は区別。
- 起動許可と入力の充足を分離。明示選択後に「作って」という動詞や議論終了宣言を必須にしない。
- 確認回答、同じ画像の修正、明示した次画像への継続、生成完了、中止・話題変更の扱いを明文化。
- `guided-clarification` と同等の、質問の必要性・優先順位・1問ずつの回答・再評価・終了判断を本体へ組み込み。別スキルへの必須依存は追加しない。
- 初回から条件が十分なら質問を追加しない。生成時の発言制約を優先し、要約や承認のためだけの往復を作らない。
- 説明量は新しい画像ごとに確定。明示済みなら再質問せず、同じ画像の修正・同条件の再試行では維持。未指定の別画像・別案には黙って流用しない。
- 「今回は」など一時例外の範囲が明示された場合の再確認を削除。例外の維持は同じ画像の修正に限定。
- READMEの導入操作を確認日付きの参考情報へ分離。起動設定の環境差と、導入後に行う確認を追記。
- 既存の会話テスト18件を更新し、16件を追加してT01〜T34へ拡張。画像テストV01〜V08を維持し、静的検査S01〜S06を整理。

### 維持した条件

画風、ブルー・ネイビー・グレーのパレット、透過標準、5〜10%の安全余白、文字量3方式の定義、原則1枚、PowerPoint編集を対象外とする範囲は維持しました。

### 採用しなかった変更

説明量を資料全体で固定する既定機能、全質問の3択強制、未選択の題材一致による起動、重複した解釈説明、毎回の最終承認は追加していません。

### 検証の区別

配布時の検査は静的検査です。ZIPの検査・作成は、アカウントへの反映や、実際の起動・会話動作・画像品質の検証を意味しません。

## 初期版 — 2026年9月18日

4ファイル構成で作成。共通のフラットスタイル、画像ごとの文字量選択、必要な確認、画像生成、確認ケースを定義しました。初期版には題材一致による起動条件があり、1.1.0で明示利用専用へ変更しています。
